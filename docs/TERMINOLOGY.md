## Repository discovery

GitHub repository topics are limited, so the repository uses the most important platform, legal-domain and multilingual terms as topics. The remaining language aliases are documented here and in `docs/LOCALIZED-ROUTES.md`, allowing GitHub and external search engines to associate the project with the relevant local terminology.
